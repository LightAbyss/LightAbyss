## 👋 About me
 
I work across **embedded systems, backend, cloud and IoT**. Python is my main tool, and I use C/C++ when I get close to the hardware. I like building things that take data from a device, move it through a reliable backend, and make it useful at the other end.
 
Currently, I'm an **Embedded Software Engineer at 3a** (Turin), working on embedded solutions for meteorological stations, ML pipelines for image classification and web-based applications. Before that I worked in software QA at BEOND (automated testing for AUTOSAR and model-based software) and at Nokia (cloud packet core testing and troubleshooting).
